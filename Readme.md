# Nim Game – Minimax AI

## Project Description
This project implements the Nim game using Python. It includes an intelligent AI player based on the Minimax algorithm with Alpha-Beta pruning.

## Features
- Nim game simulation
- Minimax decision-making algorithm
- Alpha-Beta pruning for search optimization
- Intelligent Player A and Player B
- Graphical game interface
- Game animation and visualization

## Technologies
- Python 3.11
- NumPy
- Pandas
- Matplotlib
- IPython
- ipywidgets
- Jupyter Notebook

## How to Run

1. Install the required dependencies.
2. Open the Jupyter Notebook files in VS Code.
3. Select the correct Python environment and Kernel.
4. Run all notebook cells.

## AI Strategy
The AI uses the Minimax algorithm to evaluate possible game states and select the best available move. Alpha-Beta pruning reduces unnecessary calculations and improves search efficiency.

## Project Goal
The main goal is to implement an intelligent game player capable of making strategic decisions instead of choosing moves randomly.
